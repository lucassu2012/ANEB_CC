## 4. ③ 出口 IP——登记时顺带发现一处文档方向性错误，已订正

**任务原始假设**："契约无出口字段，该 run 的出口不可知"——**核实后这个假设不成立**。

`network_snapshot.server_observed_addr` 字段**确实存在于契约里**（`result-run.schema.json`
required 字段），且逐场景都有值。此前 `M3_EXPANSION_ROUND_RUNBOOK_ADDENDUM.md` §4
把这个字段的方向写反了（"客户端观测到的服务端地址"）——本次登记核对了 schema
原文与服务端实现（`spec/schemas/result-run.schema.json:176`"服务端观察到的客户端源
IP:port"；`server/handlers_echo.go:13`"observed 回显客户端源 IP:port，供路径对账"），
方向是**服务端看客户端**：对经 CGNAT 出网的移动客户端而言，这基本就是出口 IP。
ADDENDUM §4 已同批订正（未验证部分——与外部查询页是否逐字节一致——如实标为
