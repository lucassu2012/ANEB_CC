## 4. 步骤 3：非提权触发 `/RL HIGHEST`

`current.args` 写入 `delay_lat200`。⚠ **强制无 BOM**：`shaper.ps1` 用 `Trim()` 后做
`ContainsKey`，而 **BOM 不会被 `Trim()` 去掉**，会让档名变成 `\ufeffdelay_lat200` 直接抛错。
实测写入 12 字节、首字节 `100/101/108`（非 `239/187/191`）。

🔴 **就地订正（2026-09-12，原句照留不删）—— 上面那半句是推理，不是实测，而且它是错的。**
实测（我自己在同一台机上做的）：给 `current.args` **真加上 BOM**，`Get-Content -TotalCount 1`
读回的是 **12 个字符、首字符 U+0064（`d`）**，`$MENU.ContainsKey($name)` 回 **True**
⇒ PowerShell 的读取端**自己把 BOM 吃掉了**，`Trim()` 根本没被考到。**那个失败模式不存在。**

⚠ **值得记的不是这句话错了，是它走了四层才被量一次**：本份 §4 写下这个推理 →
大脑 D-849 抄进「依据」栏 → D-851 据此裁定 → 派单要求「必须把这半句加进脚本注释」。
四层里没有一层问过「这条量过吗」，因为它**读起来完全合理**，且每一层都在引用上一层。
我在要照单加注释时才去测，测完拒绝加 ——**死代码不只是没用，它是一个邀请**：
后来人会为了「保护」一个不存在的失败模式，去改真正承重的解析逻辑。

📌 **结论怎么变**：「写入时强制无 BOM」这个**动作照留**（按字节控制输入本身是对的），
且 D-842 那条「部署须 `Copy-Item` 按字节搬运」守的是**另一件**真实存在的事 —— 无 BOM 的
`.ps1` 含中文注释时 `param()` 绑定会静默失效，那条是隔离复现过的。
**作废的只有「BOM 会让档名解析抛错」这个理由。** 正确结论配错误理由时，
**理由会被单独抄走并独立生效** —— 这就是那个形状，本条即实例。


## 10. 丢包档 `loss_5pct`（同日补验，承大脑裁定「不能从延迟档外推」）

### 10.1 判据**跑前写死**（精确二项，不是事后配的）

`n=200`、注入 `p=0.05` ⇒ 期望丢 10 次，**精确二项 95% 区间 `[4,16]` 次 ＝ `[2.0%, 8.0%]`**。

为什么非要 n=200 —— **样本量不够就是没测**：

| n | 95% 区间 | 可分性 |
|---|---|---|
| 20 | [0, 3] ＝ 0–15% | **下界 0 ⇒ 与「完全没丢」不可分** |
| 50 | [0, 6] ＝ 0–12% | 下界仍为 0 |
| 100 | [1, 10] | 勉强可分 |
| **200** | **[4, 16] ＝ 2.0–8.0%** | 下界 4，与 0 清楚可分 ✅ |

⚠ 延迟档用的 n=20 对丢包档**结构性不够**：延迟抬升 +201ms 肉眼可见，
而 5% 丢包在 n=20 时下界为 0 ⇒ **「没测到」与「没发生」同形**。

### 10.2 三阶段实测（三 IP **并行**，同一时间窗，排除时间漂移）

| 角色 | IP | 基线 | 整形中 | 收尾后 | 判定 |
|---|---|---|---|---|---|
| **目标** | 223.5.5.5 | 0/200 | **12/200 ＝ 6.0%** | 0/200 | **落带 [4,16]** ✅ |
| 近对照 | 223.6.6.6 | 0/200 | 1/200 ＝ 0.5% | 0/200 | 见 §10.3 |
| 远对照 | 119.29.29.29 | 0/200 | 0/200 | 0/200 | 不变 ✅ |

**基线三者全 0/200** ⇒ 底噪为零，**观测到的丢包只能来自整形器**。

起停记录：`START loss_5pct => --filter out --dst-ip 223.5.5.5 --loss 5 --duration 0 ...`
（PID 18596）；驱动整形中 `STATE=RUNNING`、收尾后 `1060 已卸载`；进程无残留。

### 10.3 🔴 近对照那 1 次：判决性分析，不含糊带过

近对照整形期丢 1/200（基线 0、收尾 0）。**是外溢还是底噪？**

```
假设近对照也被注入 5%：期望 10 次，95% 区间 [4,16]
实测 1 次 ⇒ 远在下界 4 之外
P(观测 ≤ 1 | 真被注入 5%) = 0.00040 ＝ 0.040%
```

⇒ **判为底噪，非外溢**：1 次与 5% 注入水平**差一个数量级**，且落在「被注入」假设的
**0.04% 尾部**。合并三阶段底噪 ＝ 1/600 ＝ 0.17%。

⚠ **这条单独写出来，是因为「近对照非零」正是最容易被顺手抹平的一格**：
写成「两对照基本不变」就把它藏了。**一个数落在判据带外，要么给出它为什么不算，要么承认没排除。**

- ✅ **丢包档真的生效**：目标 0% → 6.0% → 0%，落判据带；两对照无实质变化。
- ✅ **作用域仍精确到 IP**：近对照与目标同族相邻，注入水平差一个数量级。
- ⚠ **仍不能外推到限速档** —— 令牌桶是第三种机制，且它的**验证前提（可承压端点）未解决**，见 §7。
  📌 **追记**：该前提已解决且限速档已实测，**结果是 FAIL**（`evidence/b2_beancap_20260912/`）。
