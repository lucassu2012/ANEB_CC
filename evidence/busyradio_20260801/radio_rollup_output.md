## 无线上下文（信号档与小区一致性）

> 信号档沿用 App 侧 R1 判据（`BufferingDetector`）：弱=任一已知分量越线（RSRP<-105dBm 或 SINR<0dB）；良=已知分量均不越线（RSRP≥-95dBm 且 SINR≥10dB）；其余为中。**两个分量都不可得则记 `—`，不记档**。* = 带无线证据的 run 不足。

**档位分布**：弱 0 格 / 中 0 格 / 良 1 格
