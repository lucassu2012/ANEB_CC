### §0.2 读法红线（**五条**，违反其一即本报告被误读）

1. **UI 呈现口径 ≠ 原文 API 口径**：本报告一切时延为设备 UI 呈现口径，**绝对值不可与原文互比**
   （原文 §3.5／§八-2 已自证 API 基线含多跳代理）。可比的是**形状与斜率**，不是数值。
2. **跨口径不可相减**：通道 D（传输层）的 A1 时戳**绝不与** A0′／A2／A3／A4（UI 呈现层）相减。
3. **四态只用四个词**（`PASS` / `FAIL` / `NOT_EXECUTED` / `BLOCKED_EXTERNAL`）；未测得的量写「**待实测**」，
   **不给占位数字**（R-10）。缺席必须是显式的。
4. **本批零整形档**：所有数字都是**自然网络下的登记值**，等级 **LOW／登记级**；每格 n≤6，**不给置信区间**。

### 1.1 本报告是什么、按哪条裁定成形

PO 就「T78 报告的可答范围」取 **(a)**（REVIEW §7.4-2(a)，PO 裁 D-712(2)）：按 CAMPAIGN_PLAN v0.1.0

标题带「缩小版」。另因 E-2 提权未获常态化形式（REVIEW §7.4-1 默认 (a)：编队等 PO 开管理员窗），
**L3 整形窗从未开启** ⇒ C-1 退为「**自然对照版**」。两个限定都写进了本报告标题。

### 1.2 **实采与 (a) 计划有两处不同——正文一律按实采写**

| 项 | (a) 选项原文写的 | **本批实采** | 差在哪 |
|---|---|---|---|
| 功能 | 豆包 **F1／F6** | **F1／F2／F5／F6** 四功能 | 实采**多两个功能**（F2 深度思考、F5 联网搜索） |
| 自变量 | **× 三档**（整形档） | **零档**：仅 WiFi／蜂窝**两条件自然对照** | 实采**没有任何受控自变量** |
| F3／F4 | （未列入缩小版） | **从未开跑** | D 单元无数据的真因（D-720②） |

> ⚠ **这处差异改变 (a) 那句话的适用性**：「A/B/E/G/I 可测」是在**假定整形窗会开**的前提下写的。
> 整形窗未开 ⇒ 这五条的自变量（时延／丢包／抖动／网格）**本批全无取值**。详见 §1.4。

### 1.3 整形档：**本批逐档不覆盖**（显名，不留白）

| 整形档 | 计划取值面 | 本批状态 |
|---|---|---|
| `lat` 时延 | 多档扫斜率（A 单元自变量） | **本批不覆盖**（整形窗未开） |
| `loss` 丢包 | 2/5/10%（B・G 单元自变量） | **本批不覆盖** |
| `dn` 下行帽 | 含 16kbps 地板（C 单元） | **本批不覆盖** |
| `up` 上行帽 | 多模态上行（D 单元） | **本批不覆盖**（且 F3/F4 未采） |
| `jit` 抖动 | E 单元自变量 | **本批不覆盖** |
| `loss×lat` 复合网格 | I・J 单元 | **本批不覆盖** |

**唯一有取值的自变量是「接入方式」**：WiFi vs 蜂窝，各功能两条件自然对照。
⚠ 它**不是受控量**——制式、出口、时段均未固定（D-393 形状），故两条件之差**不得归因于接入方式**。

### 1.4 原文十单元 A–J 在本批的可答性（**按实采重判，不照抄 (a) 的乐观列**）

> ⚠ **重名警告**：本表的 A–J 是**原文十条结果单元**；CAMPAIGN_PLAN §2 另有**观察通道 A/B/C/D**。
> 两套字母不是一回事，正文每次出现都写全称。

| 单元 | 原文结论 | (a) 的标法 | **本批实判** | 理由（**理由必须与状态词匹配**） |
|---|---|---|---|---|
| **A** 时延→TTFT ~1:1 | 斜率 0.84–1.06 ms/ms | 可测 | **NOT_EXECUTED · 无自变量** | 斜率需时延档，本批零档；仅两条件不足以定斜率 |
| **B** 丢包→卡顿膝点 | loss5→67% | 可测 | **NOT_EXECUTED · 无自变量** | 膝点需丢包档 |
| **C** 下行→吞吐地板 | 133–139 tok/s | 弱化 | **NOT_EXECUTED · 无自变量** | 替代量 RCT 曲线仍需下行帽；且无服务端 token 计数 |
| **D** 上行→多模态地板 | 1.44MB<6s 需 ≥4.3Mbps | ~~红线不可测~~ | **NOT_EXECUTED · 范围外（F3/F4 未采）** | **D-720② 改标**：通道 D（免解密）在红线内可测，真因是没跑 |
| **E** 抖动→TTFT 纯平移 | ΔP95−ΔMean≈0 | 可测 | **NOT_EXECUTED · 无自变量** | 需抖动档 |
| **F** 输入体积→ms/KB | prefill 斜率 | 红线不可测 | **NOT_MEASURABLE-BY-REDLINE**（维持） | ms/KB 分解需服务端时序＝API 口径 |
| **G** 思考模式弱网代价 | ×1.6 墙钟 | 可测 | **部分可答（自然网络半）** | 弱网半需 loss 档（未覆盖）；**自然网络下 F1 vs F2 的对照本批有数据** |
| **H** token 网络零弹性 σ=0 | long 恒 1246 tokens | 红线不可测 | **NOT_MEASURABLE-BY-REDLINE**（维持） | 需服务端精确 token 计数＝MITM，本树红线外 |
| **I** 三维正交 | TTFT↔时延、卡顿↔丢包 | 可测 | **NOT_EXECUTED · 无自变量** | 需 loss×lat 网格 |
| **J** 尾部超可加 | +680ms@p95 | 弱化 | **NOT_EXECUTED · 样本与网格均不足** | 原即拉伸目标 |

**一句话范围**：本批**没有任何受控自变量**，因此十单元里**没有一条能给出「网络条件→指标」的因果曲线**。
本报告实际能交付的是两类东西：**(i) 各功能在自然网络下的登记级基线值**（TTFT 代理／cadence／e2 四态），
**(ii) G 单元的自然网络半**——F1 文本对话 vs F2 深度思考的同批对照。**其余一律显式记 `NOT_EXECUTED`。**
