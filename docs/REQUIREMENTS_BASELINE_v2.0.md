## 1. 产品定义与验收方

### 1.1 一句话产品定义

**ANEB 是一套「AI 业务网络体验」的端到端测量系统**：以 Android 探针 App + 仿真服务端，按业务 Profile（token 流式对话 / 吞吐 / 实时语音 / 第三方 App 观测）产出可复算、带诚实性标注的 KPI 与 AQS 评分，其宣称范围**按测量链各自锁定**（三条并存，实查代码常量）：主测量链（`ResultReporter` / `AbRunner`）＝`application_end_to_end_to_probe_node`（终端至仿真节点的应用层端到端）；API 探针（`ApiProbeReport`）＝`application_end_to_end_to_llm_api`；可达性探针（`AiReachabilityProbe`）＝`application_reachability_tls_no_key`。**三条一律不外推为运营商网络评级或 MOS**。

> **出处与诚实说明**：v1.0 文档开头**没有**字面的「产品一句话定义」段——最接近的三处分别是「本文件是后续 ANEB 系统开发的唯一指导文档」（v1.0 头部引言）、§1「ANEB 从单体开发模式重构为 **3 个子项目 + 1 个横切机制**」、以及横切机制的「一套方案适配多种业务模型」。上面这句是**本基线首次把它写成一句话**，取自这三处 + `claim_scope` 常量（`ResultReporter.CLAIM_SCOPE`，红线锁定）。若 PO 认为定义应另行措辞，在此改写并升版本。

### 1.2 验收方（🔴 裁项 A-2，见 §3）

**当前事实**：全仓**无外部客户定义、无外部验收标准**。交付包 v1 的状态行自述「『读者视角』终验＝**PO 验收本身**」（`DELIVERY_PACKAGE_v1_DRAFT.md` 第 3 行）。指向外部读者的**唯一线索**是 v1.0 §6 M2 行验收栏的一句括注：产出《城市 AI 业务网络体验热力卡与归因报告》「**（带数据进局点的弹药）**」（v1.0 §6 路线图表 M2 行验收栏）。

**为什么这是需求问题而非文档问题**：验收方决定验收标准怎么写（附录 A 两列因此并存），也决定主交付物排序（§3 裁项 A-1）。

## 5. 版本纪律（本文与 v1.0 的制度差别）

1. **本文可改写**。每次修订：升版本号（v2.0 → v2.1 …）+ 在 §6 修订记录加一行（改了什么 / 依据哪条 D 号或裁定 / 谁改的）。
2. **裁项回填即升版**：PO 批复三大裁项后，结论写进 §3 对应占位并升 **v2.1**，同批把附录 A 收敛为单列。
3. **v1.0 与 PLAN_ALIGNMENT 降级为历史文档**：不删除、不改写，**加横幅指向本文**（见本单同批的两处横幅补丁）。此后「计划里哪些话不算数」查 §4，不再查 §7.5 台账；台账**冻结归档**（诊断 §2.2 SPEC-1 验收第 3 条）。
4. **新增偏差加在 §4.3**，不回改历史台账。
5. **数字不写死**：门数/测试数一律「以链跑实际输出为准」（H-2/H-3 订正循环的根因，诊断 §2.3 砍④）。本文全文遵守此约。
8. **凡写进裁定材料的「这个机制是怎么工作的」描述，落笔前先实证**（本轮自纠新增）：给大脑的 7-5 裁定材料里，我把「板面格式漂移可能造成假拒」当风险写了进去——回头实证**推翻了它**：那道门用的是**纯子串匹配**、对格式漂移天然免疫，而真风险在**反方向**（已撤销的窗号、别人任务的窗号、被另一号包含的前缀，**三种都放行**）。结论方向没受影响，但**若裁定者据错误的风险描述去设计补丁，就会朝错方向使劲**。判据：裁定材料里每一句「它是这样工作的」，要么读过实现、要么跑过反例，**不能是读文档后的推断**。
7. **写「未裁 / 待办 / 缺口」之前，先查它是不是已经裁过、已经做过**（本轮自纠新增，**四次踩中**）：初稿把 D-406 已裁的 FRLOSS 当未裁重新派单、把已过期 24 天的 VC-2「未接入」当现状、把已产出 9 天并经独立核验的 M7 分布报告列为「当前可做」、把已被 D-474 重推的 n 判据印成现行。**需求基线的全部意义就是终结考古，而它的首版自己做了四次过期考古**——判据：凡落笔「待办／未裁／缺口」，先 grep 一次 `DECISION_LOG` 与 `docs/` 文件名。
6. **行号也不写死**（本轮自纠新增）：引用他文一律给「节号 + 可搜索的锚文字」，**不给行号**——本文首版引 v1.0 时写了三处行号，而同一批提交给 v1.0 顶部加了两行降级横幅，行号当场整体 +2、三处引用同时失效。**「文档写死会漂的数」这条纪律，第一个踩中的是写下它的人**（同族形状：D-537 自纠、H-2/H-3）。
