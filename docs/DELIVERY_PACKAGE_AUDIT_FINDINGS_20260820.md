- **核验精确化（比我原判更准）**：「v0.2」对 **KPI 口径**成立（`agent-qoe-kpi-v0.2` ✓），
  对 **AQS 评分版本**不成立——仓内确有一个叫 `aqs-v0.2` 的东西，但**在本语料上一分未出**。
- **且与交付包自己冲突**：L79 债务表写「解冻条件｜**评分 v0.2 冻结**｜解除条件=E-03」。
- **修法**：把 KPI 口径与 AQS 版本分开说，如「KPI 口径 agent-qoe-kpi-v0.2；
  主赛道 AQS 出 v0.1 分，aqs-v0.2 已实现但冻结（D-505）且需 continuity 源方计算」。

- **D-507 原文**：「覆盖 **3 种**网络条件超过预案要求的 2 种；**但如实标注一处缺口**——

- **D-510 侧**（我自己那份）：分两组，把 B1 并入了 WiFi，并已登记三条限制——

  **WiFi 组内部混杂**（跨 3 批次 / ≥2 SSID / 日期跨 11 天）、**共线未压到一条**。

  冲突，且 D-507"必须单列"的警示消失。更要紧的是"跨 2 网络条件"读起来像一个**干净的
