## 3. 硬约束（来自实测，不是偏好）

- **RSA 是硬约束**：P40（Android 12）系统根只有 ISRG Root X1、无 X2；ECDSA 链（YE2→X2）在手机上判不过，RSA 链（YR1→X1）判过（D-913／D-916 实测）。今日 E-01 的 sslip 证书是 ec-256/YE2——**照搬今日证书配置到新址会让手机全部握手失败**。
- **时间**：旧 sslip 证书 `notAfter = Oct 11 00:37:47 2026 GMT`（北京 10-11 08:37）；是否已被 09-10 的 acme cron 自动续期，我们正在只读核（结果会补到本文 §5）。**即便续了，也是手机验不了的 ec-256，方案 A 照做。**
- **execution-profiles 与 `/api/v1/*` 端点不变**——App 侧与判据都依赖它们（D-695②、REVIEW S3-03）。
