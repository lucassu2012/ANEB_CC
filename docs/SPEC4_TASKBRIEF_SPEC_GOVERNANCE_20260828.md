## 1. 背景与目标

诊断结论有三条落在本 lane：①口径以"新版本并列"吸收变化但从不收敛，aqs 已六支并列 + M7 后又四表，没有一页清单说清谁跟谁可比；②M3 画像字段挂 PENDING-BY-CALIBER 六周无人回头改需求口径；③流程元层自我增殖（记账提交 75%、决策日均 13+ 条、共享工作树纪律税）。本单做**规格冻结**与**治理减负**两组工作，全部以"提案 + PO 批准生效"形式落地，不擅改现行纪律。

## 2. 范围与文件边界

- **可写**：`spec/`（本 lane 属主）、`docs/` 提案文件、`tools/`。
- **只读**：`app/`（v2 lane）、`scripts/`（v3 lane——4.4 涉及 `evidence/README` 规则行时与 v3 的 3.2 合并提案）。
- **非目标**：不新增守卫层级；不做"审计的审计"；不在 PO 批准前改 CLAUDE.md 正文（提案与正文修订分两步）。

## 3. 任务分解

### 4.1 aqs 版本冻结清单（1 天）
产出 `spec/scoring/VERSIONS.md`（或 spec/README 新节，二选一并说明理由）：现役全部评分口径一页总表——aqs-v0.1 / v0.2 / aqs-token-v0.1 / aqs-voice-v0.1 / v0.2 / aqs-voice-sim-v0.1 + M7 后并列四表（WEIGHTS_VOICE_V02 族），每支五列：**定义位置 / 适用入口 / 可比范围 / 现役状态（现行・冻结・历史）/ 引用先例**。
配一条守卫：新增评分口径必须先在本表登记（形态照 D-248 常量归档先例）。
**验收**：任何人拿本表能回答"这两个分数能不能比"；守卫有反例钉住；过 verify_all 相关层。

### 4.2 portraits 三态定案提案（1 天）——SPEC-1 裁项 B 的供稿
对 `spec/portraits/` 四 App × 七参数字段逐字段出技术提案：**CAPTURED（已有）/ 改口径采（给出替代口径与误差声明，如 UI-proxy）/ 正式放弃（给出放弃后 Profile 3 还能宣称什么）**。重点：`token_interval_ms_dist`/`think_pause` 两个 PENDING-BY-CALIBER 字段——D-24/D-61 红线下永不可达成，六周没人回头裁，这次一次性裁掉。
产出交给 SPEC-1（v1）并入 `DECISION_REQUEST_20260829.md` 裁项 B；**本单不替 PO 下结论，只把三选一的代价写透**。
**验收**：七字段×四 App 全覆盖零遗漏；每个选项有可验证的代价陈述；v1 可直接引用。

### 4.3 PLAN_ALIGNMENT §7.6 差集五条裁定落地（1 天）
逐条出"改框架 or 改实现"二选一提案并推动入册：含 (e) FRLOSS 自相矛盾（框架 §4.1「丢帧可直接测」vs 生产端 NOT_MEASURABLE vs §5 红线）、C1/C2 缺权重、VC-2 barge-in / VC-3 静音心跳未接入。已由既有决策覆盖的条目直接标注归宿划掉。
**验收**：五条全部有 D 号归宿（新裁或指认既有裁定），§7.6 不再有悬置行。

### 4.4 治理减负制度化提案（0.5–1 天）
把诊断报告 §2.3"六砍四保"落成一份可批准的修订提案 `docs/GOVERNANCE_SLIMDOWN_PROPOSAL_20260829.md`：
- 决策入册新门槛（只记"改变行为/口径/边界"，摘要 ≤200 字，"自查无问题/补注"并入原条目）；
- 记账提交合并（认领/回执/登记随 feat 提交或每日一次批量）；
- 文档数字徽章化（门数/测试数由脚本生成，禁手写字面量——H-2/H-3 订正循环整体消失）；
- 审计降配（多 agent 审计只留方向性错误镜头，降为按周抽样）；
- **四保**逐条重申（四态证据语义、发布门+gate-integrity、守卫类代码突变测试、树边界与设备实况检查）。
每条给"现行条文位置 → 修订后条文 → 预计节省"。**PO 批准前一律不生效，现行纪律照旧。**
**验收**：提案可逐条批；与 v3 的 3.2（verify_all 分层与归档策略）互相引用不重复。

### 4.5 worktree 隔离迁移方案 + 演练（1 天）
方案：每执行会话独立 git worktree + 独立分支，合并统一走 PR（或大脑合并）；D 号/T 号预留区段制；O-5/O-7 共享索引纪律的退役条件写明（隔离落地即整节退役）。
演练：在本地建两个 worktree 模拟 v2/v3 并行改动 + 合并一次，证明撞车类事故（stage 卷入、搭车提交、游离空行）结构性消失。
**验收**：方案含回滚路径（worktree 不适应可退回共享树）；演练记录入 evidence；提案交 PO。

### 4.6 树边界名单补丁（0.5 天）
