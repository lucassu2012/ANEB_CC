## 本文的纪律

1. **本文不改一行代码。** 每条改动都要走正常裁定流程（决策日志 + 突变审计）后才可动手。
2. **每条都点名 md / HTML / CSV 三个面**（D-303 的课：按模块计数会把「两张表只导一张」藏起来）。
   面上**没有**这个东西时，写 **✗（不存在）**，不留空——留空会被读成「不知道」。
3. **不需要改的，写成明确的「诚实的否定」**，不省略。**否定同样是结论**，
   省略它下一个人还得重查一遍。
4. **`publish_check` 只有一个输出面**（markdown 到 stdout；无 `--html`/`--csv` 参数）。
   凡涉及它的条目，另两面一律 ✗（不存在）——这不是缺口，是它的形态。

**统计：共 19 条 = 需改动/待裁定 11 条（P0×4：A-1 / B-1 / B-2 / C-1；P1×5：A-2 / B-3 / B-4 / B-5 / C-3；
P2×2：A-4 / C-4）+ 诚实的否定 7 条（A-3 / B-6 / C-2 / D-2 / E-1 / E-2 / E-3）+ 契约级缺口 1 条（D-1）。**

> 这三个数**是从下面逐条数出来的，不是写下来的**——若有增删，先改条目再重数这一行
> （D-275：让「有哪些要对」那一侧从产物里数出来，别写成会过期的清单）。
