## 1. 概述 Overview

**ANEB Probe（Agent Network Experience Benchmark，智能体网络测试）** 是一款移动端 App，用于评估当前网络对 **AI 助手 / Agent 类应用** 的真实体验好坏，而非传统的"跑分下载速度"。它模拟 Agent 工作负载（首字延迟 TTFT、token 流是否顺滑、长文件上传、RTT/抖动、5G SA 判别等），最终合成一个 0–100 的 **Agent 体验分（AQS，Agent QoE Score）**，并用"一句人话"给普通用户结论；开发者可下钻到全量 KPI。

- **平台定位**：Android，重点适配 **华为 / HarmonyOS 终端**（无 GMS 依赖，侧载即用）。视觉语言为 **Apple / iOS 质感**（系统蓝、iOS 语义色、毛玻璃材质、连续圆角、弹簧动效）。
- **两种视图模式**：`简洁`（普通用户）与 `专业`（开发者），顶部分段控件切换。
- **深浅色**：跟随系统，两套完整配色。

## 4. 屏幕清单 Screens / Views

所有手机屏设计画布 **360 × 720**（逻辑 dp/pt）。设备外壳 `.phone` 内容区 300×648（展示用），实现时按目标屏宽自适应。顶部为**毛玻璃浮层 chrome**，内容从其下方滚过（不要用实心色条切走固定高度）；底部操作区同为毛玻璃浮层。

### 4.1 首页 `home` —— 一键测试
- **用途**：进入即测。整屏只有**一个大决定**：开始测试。
- **布局**：顶部品牌行（左 `A` + 蓝色 `NEB` 字标 + 副标"智能体网络测试"，右分段控件 简洁/专业，此屏顶栏为 `.bare` 透明，无玻璃）→ 居中 216×216 仪表盘，中心为 62px 圆形蓝色 GO 按钮 + 三层向外扩散的**脉冲环**（呼吸）→ 提示文字"轻触开始 · 约 90 秒" → 底部"上次成绩"chip（左侧 38px 圆角分数徽标，右侧两行文案 + 右尖角 ›）。
- **关键组件**：脉冲环 `.pulsering`（3 个 `span`，`pulse` 关键帧 2.6s，延迟 0/0.9/1.8s，scale 1→2.7 + 透明 0.55→0）；GO 按钮 62px 圆、背景 `--brand`、阴影 `0 10px 30px -6px`（品牌色 70%）。

### 4.2 测试中 `testing` —— 实时反馈
- **用途**：展示测试进行中的**持续反馈**，让用户感知"正在发生"。
- **布局**：顶栏标题"测试中" + 副标"2 / 3 · 编码 Agent 流" → 仪表盘边填充边计数（示例 62），中心分数带闪烁省略号 → 阶段行 `.phase`（左侧 `--good` 色心跳点 `.live`，`ping` 关键帧 1.4s）+ 文案"正在测：token 流是否顺滑" → **token 流点阵** `.streamstrip`（每字符一个 5px 圆点：`1`=正常绿点、`0`=暗点 `dim`、`s`=红色略大 `stall`=卡顿）→ 2×2 实时迷你指标网格（首字延迟 / 卡顿 / 信号 RSRP / 制式）。
- **要点**：点阵按顺序逐个 scale 0→1 入场（间隔 20ms）；**缺口/红点即卡顿**，是这一屏的核心叙事。

### 4.3 结果 · 普通用户 `result-simple` —— 简洁视图（★ 主结果屏）
- **用途**：给非技术用户一眼看懂的结论。
- **布局**：顶栏（玻璃）标题"测试结果" + 副标"电信 5G SA · 深圳 · 刚刚" + 分段控件（简洁 高亮）→ 208×208 仪表盘：外圈灰底轨、彩色进度弧（`stroke-width:10`、圆头）、内圈 48 刻度点阵（点亮到分数）；中心 **64px 巨大分数** + 分档标签（优秀/良好/…）+ "Agent 体验分" → **结论句 `.verdict`**（16px 居中，关键词用分档色加粗）→ 三瓦片 `.tiles`（响应速度 / 卡顿次数 / 上传 Mbps，每片 数值 + 名称 + 优/良/可/差角标）→ 底部玻璃操作区两按钮（次要"查看详细数据" 幽灵 + 主要"分享成绩" 蓝）。
- **示例内容**：89 分 · 优秀 · "你的网络**很适合 AI 助手**——响应快、几乎不卡顿，编码和长对话都能跟上。" · 瓦片 35ms(优)/0(优)/12.5(良)。

### 4.4 结果 · 开发者 `result-dev` —— 专业视图
- **用途**：给技术用户全量下钻。可滚动长内容。
- **布局（自上而下，`.content` 可滚）**：
  1. **AQS 头部** `.devhdr`：左 34px 分数（89.2）+ 右说明（优 · AQS · 低置信 / 版本 / claim）。
  2. **AQS 子分与权重**：7 行 `.kpirow`，每行 名称+权重 / 进度条 `.kbar`（填充色按分档）/ 数值。T1 首字 20% / T3 卡顿 20% / T2 间隔 15% / U1 上行 15% / U2 循环 10% / N1 RTT 10% / N2 抖动 10%。
  3. **KPI 明细（S2 编码 Agent）**：TTFT / stall率 / RTT P50 / 上行 U1，每行带 优/良 角标 `.gchip` + 主值 + 副注（P95、含resume、抖动、剔慢启动）。
  4. **无线层（671 样本 · 1Hz）** `.datagrid` 2×2：制式(5G SA·n78) / RSRP(−93.1dBm) / SINR(8.5dB) / PCI·TAC。

  6. 底部玻璃操作区：导出 JSON / 导出 CSV（两幽灵按钮）。

## 6. 交互与行为 Interactions & Behavior

1. **按压即反馈**：任何可交互元件 pointer-down 立即反馈（不等松手），`transform: scale(.96)`，`120ms` ease-out（类 `.press`）。
2. **弹簧而非固定时长**：默认临界阻尼（无过冲，response .3–.4）；只有手势本身带动量（甩/拖放）才用 `--ease-spring` 加轻微过冲。
3. **脉冲 · 持续状态**：进行中的状态持续反馈（GO 按钮呼吸环、实时点心跳），不是只在结束时。
4. **材质会"到场"**：玻璃浮层进出时**同时动模糊和缩放**（`blur(6px)+scale(.94)+opacity 0` → `blur(0)+scale(1)+opacity 1`，.5s ease-out），读作真实材质抵达而非淡入。
5. **滚动边缘用渐隐不用硬分割线**：内容进入玻璃浮层区域时用 `mask-image` 线性渐隐（顶部 ~96px、底部 ~72px 处淡出），不压 1px 描边。
6. **尊重"减弱动效"**（`prefers-reduced-motion: reduce`，**务必实现**）：弹簧/脉冲 → 交叉淡入；按压缩放 → 透明度变化；数字与弧线 → **直接呈现最终值**。反馈更温和，绝不消失。

**入场动效（缩略图/首帧安全，详见 `aneb.js`）**：所有屏幕**在无 JS 或截取首帧时也是静态正确的**——入场是从"接近最终态"温和 settle，绝不从空白开始，数字永远显示最终值。
- 进度弧：先写入最终 `stroke-dashoffset`，再从"约半程"settle 到最终（`.6s ease-out`）。
- token 流点阵：逐点 scale 0→1，间隔 20ms。
- KPI 进度条：先写最终宽度，再从 ~55% settle 到最终。

## 7. 状态管理 & 结果屏参数化 State

**核心状态**：`viewMode: 'simple'|'dev'`（分段控件）· `theme: 'dark'|'light'`（跟随系统）· `phase: 'idle'|'testing'|'result'` · `score: 0–100` · `band: 'exc'|'good'|'fair'|'poor'` · 各 KPI 明细 · REACH 结果。

**结论文案系统**（按 AQS 分档 + 最拖后腿的 KPI 生成"一句人话"，不堆术语）：
- 优 85+：`很适合 AI 助手`——响应快、几乎不卡顿。
- 良 70–85：`日常够用`——对话流畅，大文件上传偶尔多等。
- 可 55–70：`能用但会卡`——长回答可能一顿一顿地出。
- 差 <55：`体验较差`——连接不稳，AI 助手常中断。

**仪表盘参数化**（来自结果屏模板 `reference/…dc.html` 的逻辑，可直接移植）：
- 圆周常量 `C = 578.05`（半径 r=92 的周长），SVG 整体 `rotate(-90deg)` 使弧从正上方起、顺时针填充。
- 进度弧偏移：`strokeDashoffset = C * (1 - score/100)`。
- 分档色映射：`exc→--exc, good→--good, fair→--fair, poor→--poor`，同时赋给弧、分数、分档标签、瓦片角标。
- 刻度点阵：`N=48`，点亮数 `active = round(score/100 * N)`；每刻度 `i` 角度 `(i/N)*2π`，内半径 `rin=74`、外半径 `rout=84`，圆心 (106,106)；点亮用 `--band`/opacity .92，未亮用 `currentColor`/opacity .16，`stroke-width 2.4` 圆头。
